# Find Your Feet

Simple, lightweight add-on that turns on Self Highlight native options (icon, ground circle, outline) automatically upon entering Raids and Dungeons, and turns it off elsewhere.

## Defaults

Highlights:
- Icon = enabled
- Circle = enabled
- Outline = disabled

Locations:
- Raids = enabled
- Dungeons = enabled

## Commands

/fyf circle : Toggle the circle highlight around your feet
/fyf icon : Toggle the icon highlight above your head
/fyf party : Toggle the automatic activation of enabled highlights while in 5-man instances
/fyf raid : Toggle the automatic activation of enabled highlights while in raids
/fyf verbose : Toggle the chat messages sent when Self highlights gets enabled or disabled

## Troubleshooting

If highlights that should be enabled aren't showing when entering a raid/dungeon, try to turn on all the options in the In Game options panel, then exit and enter the instance again.
